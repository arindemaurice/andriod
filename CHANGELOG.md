# Changelog

## 1.0.0 - Initial Android release candidate

- Replaced the server-dependent WebView shell with a lightweight native Kotlin Android application.
- Added Gemini API chat using Gemini 3.8 Flash.
- Added encrypted API-key storage backed by Android Keystore.
- Added local SQLite chat history and persistent memory notes.
- Added offline date/time and memory commands.
- Added optional speech-recognition handoff.
- Added GitHub Actions APK build and Termux installation guide.
- Targeted Android 9+ with Samsung Galaxy A04 as the first confirmed device.
